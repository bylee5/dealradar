# DealRadar

여러 핫딜 커뮤니티를 한곳에 모아 보고, **갑자기 크게 할인하는 상품(급할인)** 을 표시하며,
**사고 싶은 상품을 등록해 두면 조건에 맞는 딜이나 목표가 도달 시 알려주는** 로컬 웹 앱입니다.

- Python **3.6+** (Flask 2.0.3 / BeautifulSoup 4.11 고정, 표준 라이브러리 `sqlite3`·`urllib` 사용)
- DB 서버나 별도 스케줄러가 필요 없습니다. `python run.py` 하나로 실행됩니다.

## 설치 및 실행

```bash
python -m venv venv
venv\Scripts\activate          # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python run.py                  # http://127.0.0.1:5000
```

| 옵션 | 설명 |
|---|---|
| `--port 8080` / `--host 0.0.0.0` | 포트·바인드 주소 변경 (같은 네트워크의 휴대폰에서 보려면 `0.0.0.0`) |
| `--crawl` | 수집 1회 실행 후 종료 (cron / 작업 스케줄러용) |
| `--no-scheduler` | 웹 화면만 실행 |

DB 파일은 `data/dealradar.db` 에 생성됩니다 (`DEALRADAR_DB` 환경변수로 변경 가능).

## 기능

### 1. 핫딜 모아보기
| 사이트 | 방식 |
|---|---|
| 뽐뿌 (국내 + 해외뽐뿌) | RSS |
| 루리웹 핫딜 | RSS |
| 클리앙 알뜰구매 | HTML |
| 퀘이사존 핫딜 | HTML |
| 에펨코리아 핫딜 | HTML |
| 아카라이브 핫딜 | HTML |

- 기본 5분마다 수집하며, 상단 **지금 수집** 버튼으로 바로 수집할 수도 있습니다.
- 카테고리(육아, 배드민턴, 스포츠, 디지털, 게임, 식품, 생활, 패션, 상품권)는 **제목 키워드**로 분류합니다.
  키워드는 설정 화면에서 고칠 수 있고, 카테고리를 새로 추가할 수도 있습니다.
- 검색, 사이트·카테고리 필터, 최신순/핫한순/낮은가격순 정렬, 종료된 딜 숨기기를 지원합니다.

### 2. 급할인 감지
다음 중 하나라도 해당하면 빨간 **급할인** 배지를 붙입니다. 기준값은 설정에서 바꿀 수 있습니다.
- 제목에 적힌 할인율이 기준 이상 (기본 40%)
- '역대가', '대란', '가격오류', '반값' 같은 강한 키워드
- **같은 상품이 예전에 올라왔을 때 가격보다 기준 이상 쌈** (기본 25%) — 수집 이력이 쌓일수록 정확해집니다
- 3곳 이상의 커뮤니티에 동시에 올라옴
- 추천수가 기준 이상 (기본 20)

*자동 알림 카테고리*(기본값: `육아,배드민턴`)에 급할인이 올라오면 감시를 등록하지 않아도 알림을 보냅니다.

### 3. 관심상품 감시
- **키워드 감시**: 새 핫딜 제목이 조건에 맞으면 알림을 보냅니다.
  - 공백으로 구분한 단어는 모두 포함해야 하고(AND), 쉼표로 구분하면 그중 하나만 맞아도 됩니다(OR).
    예: `아스트록스 77, 나노플레어 800`
  - 제외어, 최대 가격, 카테고리 조건을 걸 수 있습니다.
  - 딜 목록의 **+감시** 버튼을 누르면 그 딜의 제목으로 키워드가 미리 채워집니다.
- **URL 가격 추적**: 상품 페이지 가격을 주기적으로 확인합니다(기본 60분). 가격 추이 그래프를 보여 주고,
  목표가 도달·직전 대비 N% 하락·추적 최저가 갱신 시 알림을 보냅니다.
  - **다나와 상품 페이지**(`prod.danawa.com/info/?pcode=...`)에서 가장 안정적으로 동작합니다. 쇼핑몰 최저가 기준입니다.
  - 쿠팡, G마켓, 네이버 스마트스토어는 봇 차단 때문에 대부분 실패합니다. 같은 상품을 다나와에서 찾아 등록하세요.
  - 자동 인식이 안 되는 사이트는 '가격 CSS 선택자'를 직접 지정할 수 있습니다.

### 4. 알림
- 앱 안의 **알림** 화면 (상단에 읽지 않은 알림 개수 배지)
- 텔레그램 봇 / Slack·Discord 웹훅 (설정 화면에서 입력한 뒤 '테스트 보내기'로 확인)
- 처음 수집하는 사이트의 기존 글로는 외부 알림을 보내지 않습니다(알림 폭탄 방지).

## 구조

```
run.py                     진입점 (웹 서버 + 백그라운드 스케줄러)
config.py                  기본 설정
dealradar/
  crawlers/base.py         HTTP, 가격/쇼핑몰/날짜 파싱, Deal 모델
  crawlers/rss_sites.py    뽐뿌, 루리웹
  crawlers/html_sites.py   클리앙, 퀘이사존, 펨코, 아카라이브  ← 사이트 구조가 바뀌면 여기만 수정
  categories.py            기본 카테고리 키워드, 분류기
  scoring.py               급할인 판정 / 핫 점수
  collector.py             수집 → 분류 → 유사 상품 비교 → 저장
  watcher.py               키워드 감시, URL 가격 추적
  price_tracker.py         상품 페이지 가격 추출 (JSON-LD / 메타 태그 / 선택자)
  notifier.py              앱 내 알림, 텔레그램, 웹훅
  scheduler.py             백그라운드 스레드
  web.py, templates/, static/   Flask 화면
tests/test_core.py         단위 테스트 (python -m unittest discover -s tests)
```

**새 사이트 추가하기**: `crawl()` 이 `Deal` 목록을 반환하는 클래스를 만들고 `crawlers/__init__.py` 의 `ALL_CRAWLERS` 에 등록하면 됩니다.

## 참고
- 개인용 도구입니다. 수집 주기를 너무 짧게 잡으면 사이트에서 차단될 수 있으니 5분 이상을 권장합니다.
- 일부 사이트는 Cloudflare 때문에 `requests` 라이브러리를 차단합니다. 그래서 표준 `urllib` 를 사용합니다.
- 딜은 90일이 지나면 자동으로 삭제됩니다 (`config.DEAL_RETENTION_DAYS`).
